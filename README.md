# Timonexus-Planora

Is a planning tool for communities and organisations for their lessons and their learning topics, related to clients or members. It has an integrated calendar, an topic administration, as well as an member and teacher overiew an administration. This project is for now for free, in the future it is possible that it grows that much, so i have to monetarize that whole project. But thats music form the future. This program is currently work in progress, so I don´t have any documentations about the useabilty or something similar. This readme is used only for documenting the steps I done for me, kinda a devlog.
